## Top picks

### merge-now
- **#1754 preserve wiki pages when LLM merge output is invalid.** `rewriteMerge()` fell back to the candidate page when the LLM returned empty/no-frontmatter text; the candidate holds only the new facts, so the existing page (old facts, sources, links) was silently overwritten and reported as written. The fix throws instead; `commitCandidates()` already catches per page and records `mergeErrors` + log entry, so the old page survives and a retry still sees it. Good tests (6 invalid outputs, commit-level retry). Risk: frontmatter-only replies now count as failures (intended).
- **#1470 propagate improved scores in multi-hop wiki search.** BFS only pushed a node to the next frontier on first visit, so a later, stronger arrival in the same layer never propagated; search ranking depended on seed order. Fix keeps the strongest arrival per node per layer. Contained (one function) with an exhaustive oracle test over all 4-node graphs. Low risk.
- **#1390 wiki-summary maxOutputTokens 1024 -> 4096.** With reasoning models the hidden reasoning consumes the 1024 budget and the summary comes back empty (finishReason=length). Our `LLM_MODEL` is env-driven, so this can happen to us. One line; only cost is a higher cap.
- **#1262 enforce auto-sync build concurrency.** `sync()` only enqueues; the scheduler freed its worker slot immediately, so the concurrency limit never bounded real CodeGraph builds (CPU/disk spikes when many repos are due). Now awaits `cgService.onIdle(id)`. Risk: a hung build holds its slot (but that is what a limit means).
- **#1141 exit when server startup fails.** On startup failure the process set `exitCode` only; open handles (Langfuse) kept it alive and not listening. `process.exit(1)` lets `start-combined.sh` and the container restart policy react. Small, has a spawn-based test.

### consider
- **#685 (proxy part only).** Verified in our HEAD: `/v3/admin/rate-limits` GET/PUT/DELETE are registered with no auth (`MemoryProxy/src/server.ts:158-161`), and `checkAdminAuth` returns ok when `admin.apiKey` is empty (`MemoryProxy/src/routes/admin-auth.ts:8`). Our proxy is reachable beyond localhost (tailnet), so anyone could set qpm=1. Cherry-pick the `enforceAdminAuth` wrapper in rate-limits.ts. Do NOT take blindly: the fail-closed change to `checkAdminAuth` affects all admin endpoints when no key is set, the `--` URL ban rejects valid repo names, and async DNS validate changes callers. PR is stale (conflict-upstream). needs-owner-read.
- **#1107 SSRF validator IPv6 / IPv4-mapped.** Real bypass (`[::ffff:127.0.0.1]`, `[::1]` with brackets) in the Git source fetcher. Clean with tests, but `fc00:`/`fd00:` only matches those exact hextets; prefer porting #1554's regex `fc[0-9a-f]{2}:|fd[0-9a-f]{2}:` and `.localhost` handling into it.
- **#1616 cacheable ingest catalog prefix.** Puts the identical existing-page catalog first in all ingest prompts so OpenAI/Anthropic prefix cache hits; meaningful token savings on large wikis. Prompt order change can shift LLM output; spot-check one ingest before adopting.
- **#1004 refresh stale service_url (route hunks only).** Existing wiki/code-graph rows keep the service_url from creation time; if `KNOWLEDGE_PUBLIC_BASE_URL` changes (our compose default `host.docker.internal:8424/v3` may not resolve from a host-side agent), idempotent create now refreshes it. The `deploy/global-images` changes do not apply to our compose deployment.
