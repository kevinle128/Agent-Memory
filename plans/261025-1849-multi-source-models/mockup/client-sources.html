Client Access Endpoint

Current instance: Agent Memory (default)

Ghi chú

  • Model sources là dropdown. Client dùng nhiều nguồn: chọn nhiều (checkbox, tag hiện trong ô, × để bỏ). Claude Code và Codex: cùng dropdown nhưng chỉ chọn một. Danh sách chỉ có nguồn đúng định dạng: Claude Code thấy nguồn Anthropic (ví dụ sub-claude, api-anthropic, api-deepseek), Codex thấy nguồn Responses (ví dụ sub-openai, api-openrouter). Model gửi lên giữ nguyên tên, không có tiền tố.
  • Mọi client còn lại (CodeBuddy, WorkBuddy, dsh, OpenCode, omp, Hermes, OpenClaw) gọi model dạng <source>/<model>.
  • Tag: chấm màu cho loại ( subscription, API key), tên nguồn, số model; × hiện khi rê chuột. Nguồn đang tắt: chữ xám kèm nhãn Off, model của nó không có trong /v1/models. Nguồn đang tắt không hiện trong danh sách chọn. Nguồn đang được client nào chọn thì không tắt và không xoá được: Panel báo các client đang dùng và yêu cầu gỡ ở trang API Key trước; Core cũng từ chối. Vì vậy không có trạng thái "đã chọn nhưng đang tắt".
  • Thêm thẻ oh-my-pi (omp) (đang thiếu). Thành viên chỉ xem; admin sửa.
  • Danh sách nguồn mẫu trong mockup (api-anthropic, api-deepseek, api-openrouter) chỉ để minh hoạ; prod hiện chỉ có sub-claude và sub-openai.

Ghi chú

  • Không còn khối "Use as a source". Tên nguồn của pool cố định: sub-claude / sub-openai.
  • Nút Selected models hiện số model đang bật / tổng. Bấm để mở hộp chọn model: tìm kiếm, bật/tắt từng model, bật/tắt tất cả, nút Refresh lấy lại danh sách từ gói.
  • Thành viên mở được hộp nhưng chỉ xem; công tắc bị khoá.
  • Bấm công tắc pool: sub-claude đang được Claude Code, omp, Hermes chọn nên Panel chặn và liệt kê các client đó.

Ghi chú

  • Add provider mở form: provider, base URL, API key, định dạng, tên nguồn (gợi ý sẵn, sửa được tới khi lưu). Không còn ô chọn agent.

  • Tắt hoặc xoá api-deepseek bị chặn vì dsh và omp đang dùng; api-openrouter không ai dùng nên xoá được.
  • Nguồn mới tạo chưa gán cho client nào; gán ở trang API Key.
